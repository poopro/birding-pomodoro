# 賞鳥番茄鐘 · Birding Pomodoro

> 第五週作業 · 用 Vibe Coding 做出一個互動網頁
> 國立陽明交通大學 114481030 HSS二 陳宏威

一個會在休息時「揭曉一隻鳥」的番茄鐘。
**29 張照片全部是我自己 2025–2026 年在臺灣各地拍的鳥。**

## 線上demo

> 部署後連結貼在此（Settings → Pages 取得）

## 特色

- **番茄計時**：專注 25 / 短休 5 / 長休 15，時長可自由調整
- **計時不會漂移**：用 `Date.now()` 截止時間戳反推，切分頁、休眠都準
- **本輪目標種**：開始專注時抽一隻鳥，休息時揭曉牠的照片與觀察筆記
- **賞鳥圖鑑**：19 種、29 張實拍照片，可依科別篩選、關鍵字搜尋、點擊看大圖
- **觀察日誌**：累積分鐘、番茄數、發現種數、連續天數、近 7 天長條圖
- **全離線**：單一 `index.html`，零 CDN、零外部相依，雙擊就能開

## 使用

直接開啟 `index.html` 即可，不需要安裝任何東西。

| 快捷鍵 | 功能 |
|---|---|
| `空白鍵` | 開始 / 暫停 |
| `R` | 重設 |
| `1` `2` `3` | 切換 專注 / 短休息 / 長休息 |
| `Esc` | 關閉鳥種大圖 |

## 技術

- 單一 HTML 檔案，CSS / JavaScript 全內嵌
- 原生 JavaScript，無框架、無 CDN、無外部字型或音檔
- 照片以 Pillow 轉 **WebP**（長邊 1280px、q=72）後以 base64 內嵌，共 2,031 KB
- 音效以 **Web Audio API 即時合成**（鈴聲、環境風聲、鳥鳴），不使用音檔
- 狀態存於 `localStorage`（key = `birdpomo.v1`）
- 響應式：桌面雙欄 → 860px 以下單欄，390px 手機實測無溢出
- 支援 `prefers-reduced-motion`

## 檔案
